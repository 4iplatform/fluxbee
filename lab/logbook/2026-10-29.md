# 2026-10-29 — The WF track's Case 0, shipped as 0.1.90

Where the track stands is in [wf-orchestration-v1](../../docs/wf-orchestration-v1.md) §5.1. The
release's facts are in the ledger's [0.1.90 entry](../DEPLOYMENTS.md).

## How it went

- **The build:** one agent built the seven decisions of Case 0 and the "fixed with them" list,
  from §5.1 as the spec.
- **The review round:** four reviewers, each blind to the others' lens (the engine, security, the
  language, the docs). Two findings came up independently in two lenses:
  - **A late answer started a new instance.** An agent answers with the request's own name, so the
    engine took an answer to an ended instance as a new trigger, and asked the agent again: a WF↔AI
    loop that spends model calls.
  - **Any node could have SY.timer fire an instance's timer.** SY.timer schedules a timer for any
    target, and fires it under its own name. The WF now takes a fire only for a timer it
    scheduled.
- **What else the round found:**
  - **The engine:** at least once had turned a crash into a crash loop. An event that killed the
    node stayed in the journal and killed it again at every start. The concrete trigger was a
    guard left running past its timeout, reading the state while the next transition wrote it.
    Guards now run on the caller's goroutine, and an event gives up after 3 starts.
  - **The language:** an integer written in a definition went out as `3.0`, which Rust rejects
    where it expects an integer. This was a regression of the change itself.
  - **The docs:** the main example waited for answers an agent never sends.
- **All 27 items were fixed before the build.** One more after it, by me: the round had made a
  `$ref` with a mistyped root a literal, and it is refused again.
- **The gate,** a real WF through SY.admin, `WF.gate0190@worker1`, which asks `AI.pruebas`:
  - the exchange closed end to end, on a 60 s timer and `event.timer_key`;
  - a restart and a redeploy kept their instances;
  - a forged fire, a timer scheduled by another node and an unauthorized verb were all refused;
  - Archi's seeds upgraded.
- **Kept open, by decision or recorded:**
  - an instance's thread drives it, whoever sends it (A-123, the open security topic of decision
    6);
  - `thread_id_ref` to an agent loops (A-116, Case 2);
  - SY.timer takes a timer for another node (A-115).
