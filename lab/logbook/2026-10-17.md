# 2026-10-17 — Cognition per communication, NATS deleted and LLM usage recorded (A-70, stages 2 and 3, from 0.1.77 to 0.1.79)

## The operator's decisions

- **Stage 2 was talked through before it was designed.** The facts were presented: cognition on the
  motherbee and worker1, the worker1 reload broken because it has no database, no `AI.*` node
  running in PROD, 597 turns stuck on the ingress.
- **Cognition belongs to the interlocutors:** *"la parte cognitiva es de los interlocutores no de
  que hive está o que nodo es... Cognitive necesita referencia y armado de los mensajes entre ilk,
  los nodos son mecanismos, igual que el router, el dueño del turn es el dueño de la
  comunicación"* (the cognitive part belongs to the interlocutors, not to which hive it is on or
  which node it is... Cognitive needs reference and assembly of the messages between ilks; the nodes
  are mechanisms, the same as the router; the owner of the turn is the owner of the communication).
  - I proposed centralizing cognition on the motherbee. The operator rejected it: cognition is on
    the workers so that the AI nodes read their memory through local SHM (*"no quiero cambiar
    eso"* (I don't want to change that)).
  - The operator suggested putting the worker name in the references. We withdrew it: a memory with
    the hive inside it splits when the agent changes node.
  - The outcome: the agent's router passes both directions to its local cognition, and the
    communication is `(thread_id, agent ILK)`.
- **SY.policy goes away** (*"nació como una extensión que no ocurrió, si no hace nada sacalo.
  molesta"* (it was born as an extension that never happened; if it does nothing, take it out. it
  gets in the way)). **NATS is deleted entirely,** with no legacy. The test data can be deleted.
- **The LLM cost stays as it is** (*"construir la memoria coherente y consolidada va a costar
  cognitividad"* (building the coherent and consolidated memory is going to cost cognitivity)).
  Today only the `AI.*` nodes consume cognition; more consumers, later.
- **Stage 3 (tokens)** is discussed when stage 2 is finished.

  - SY.policy does not run on any hive; NATS received nothing; health clean;
  - everything from the test was deleted: nodes, identities, tenant, memory regions and rows.

  eight scripts, SY.policy and `thread_seq`.

  - with SY.storage held back, the admin answered `ORCHESTRATOR_BOOTING` instantly during the
